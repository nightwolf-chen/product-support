支持 — 美图壁纸（Wallpapers）

美图壁纸（iOS，iPhone，需 iOS 15 及以上，竖屏）· 免费（含广告）· 无需注册 · English version

感谢使用美图壁纸！常见问题解答如下。如需更多帮助，请通过 GitHub Issues 联系我们。

常见问题

如何把图片设为壁纸？

iOS 不允许应用直接更换壁纸。在美图壁纸中打开图片，点保存按钮将其存到相册。 然后打开照片应用，找到该图片，点共享 → 用作墙纸，调整后点 添加即可。

为什么应用要请求相册权限？

仅在您保存图片时才会请求，且为“仅添加”权限，用于把壁纸写入相册。应用不会读取或上传 您已有的照片。

为什么应用请求跟踪权限？

美图壁纸免费，靠广告维持开发。跟踪提示（App 跟踪透明度）用于让您选择是否允许个性化广告 （Google AdMob）。您可随时在 iOS 设置 → 隐私与安全性 → 跟踪中更改选择。 详情见隐私政策。

搜索无结果 / 加载很慢

搜索结果实时来自多个图片服务，需要联网。请检查网络，换更简单的关键词试试 （如 nature、ocean），下拉重试。即使某个图片源故障， 其他来源的结果仍会显示。

发现、分类、收藏都在哪里？

  • 发现 — 精选图片流，支持随机刷新与无限滚动。
  • 分类 — 精选专辑（自然、动物、动漫、汽车、城市……）。
  • 我的 / 收藏 — 您的收藏、离线专辑与缓存管理。

我的收藏不见了

收藏只保存在本机（无账号、无云同步）。删除应用或清除其数据会永久删除收藏，无法恢复。

如何释放空间 / 清理缓存？

打开我的页面，使用缓存显示 / 清理缓存功能。已保存到相册的大图请在 照片应用中管理。

如何举报不良图片？

图片来自第三方服务（Unsplash、Pexels、Pixabay、Flickr、Openverse、Wikimedia Commons、Bing）。 请提交 issue，注明 看到图片时的搜索词或分类并描述问题，我们会复查相关来源。

支持哪些设备？

运行 iOS 15.0 及以上的 iPhone，竖屏使用。暂无 Android 版本。
